Kontrol Proses kelas XI, topik 4

Simulator kontrol PID

Sebuah tangki berisi air bersuhu 30 °C. Pada detik ke-10, set point dinaikkan menjadi 60 °C. Pengendali suhu (TIC) mengatur daya pemanas dari 0 sampai 100% supaya suhu air mencapai set point. Geser nilai Kp, Ki, dan Kd, lalu amati bagaimana grafik berubah.

Pengaturan pengendali

Pilih mode cepat, atau geser sendiri.

Seberapa kuat pengendali bereaksi terhadap error saat ini.

Menjumlahkan error dari waktu ke waktu untuk menghapus offset.

Meredam laju perubahan suhu supaya tidak melewati set point.

Tiga aksi dalam PID

P, proporsional

Output sebanding dengan error. Kp besar membuat respon cepat, tetapi kontrol P saja selalu menyisakan offset dan bisa berosilasi.

I, integral

Output bertambah selama masih ada error, sehingga offset hilang. Ki terlalu besar membuat suhu melewati set point dan berayun.

D, derivatif

Output melawan perubahan yang terlalu cepat, seperti rem. Kd membantu mengurangi overshoot, tetapi peka terhadap noise sensor.

Coba dan catat

  1. Pilih P saja. Berapa offset-nya? Naikkan Kp ke 5, lalu ke 8. Apa yang terjadi pada offset dan bentuk grafik?
  2. Pilih PI. Apakah offset hilang? Bandingkan overshoot saat Ki = 0,02, Ki = 0,05, dan Ki = 0,15.
  3. Pilih PID, lalu ubah Kd dari 0 ke 20. Bagaimana pengaruhnya terhadap overshoot dan waktu tunak?
  4. Nyalakan gangguan. Bandingkan mode P saja dan PI: mode mana yang mengembalikan suhu ke 60 °C?
  5. Pilih Terlalu agresif. Jelaskan mengapa daya pemanas (MV) melonjak ke 0% dan 100% berulang kali.
